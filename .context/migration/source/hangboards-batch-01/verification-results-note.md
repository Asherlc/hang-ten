# What the packaged verification record covers

verification-results.json was produced by a fresh import/check of this model tree before the final ZIP was assembled. It binds the actual model hashes, material/contact identities, current renders, source reproducibility and per-model file hashes. The final ZIP itself is verified separately in hangboards-batch-01-verification.json, supplied outside the ZIP to avoid circular hashing. Neither record asserts a full source-fidelity pass.
