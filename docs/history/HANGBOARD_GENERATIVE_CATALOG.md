# Historical generated-catalog inventory

Before direct package bundling, the repository kept a generated hangboard
catalog as experimental artwork and outline material. The importer retained
that material in flat `Hangboards/<slug>/` draft packages, and quarantined the
same material below an approved package's `review/unreviewed-generated-catalog/`
directory when the slug already had an approved package.

Those retained files document the earlier experiment only. They are not
approved package evidence, runtime metadata, or app resources. The active
workflow and shipping rules are documented in [Adding a hangboard](../ADDING_A_BOARD.md).
