# YY Baguette Evo native geometry

Native 520 × 50 mm cylindrical body with stepped grip profiles, nineteen contact identities and four independent through-bores.

The final solid is Joined_SeamBox_z0. Deliberately authored native YZ sketch sections preserve the shared stepped walls, with 2.5 mm native roundovers on twelve front lip edges. Contact surfaces are actual open native body surfaces; twenty contact nodes map to nineteen identities because the rounded tray has two regions. Eighteen native lip/floor witness pairs in depth-witnesses.json verify the maker depths without confusing a stepped wall bounding box with grip depth. The witnesses are tied to native parameters. Four independent bores are radius 2.5 mm, X −246, −231, 231, 246 mm; Y −25..25 mm, Z 0. Their measured native channel lengths are 50 mm each. Evidence shows exterior rear returns; no hidden U-channel is invented. Native half-space imprints retain the contact boundaries without adding solid material; one coplanar seam offset is 0.00001 mm to avoid a kernel degeneracy.

Exact manufacturer image bytes, URLs, support mappings and user source approval are retained in source-register.json and evidence-review.html. Cross-section measurement uses only the approved Git display mesh from d0e4e95191e4a76822815bb4eeef3a32caa6fea0; no pixels were traced. All geometry consists of native analytic Sketcher/Part/PartDesign features. Native coordinates are millimeters, X right, Z up, front −Y; runtime coordinates are (X,Z,−Y)/1000. No materials, textures or mounting hardware are present.

Native validation reopens and recomputes the saved document, verifies constrained sketches, valid solids and open contact regions, exercises an editable dimension, then restores geometry and verifies source bytes remain unchanged. The embedded manifest replaces the physically removed board.json. Native route generation and final app review are tracked separately; this document does not claim human app approval.

The original 2 mm cord display radius is retained. A single oblique plane route came within 1.975 mm of the front bore lip; every available planar mouth opening has only about 2.5 mm clearance, so increasing its uniform offset alone cannot solve the three-dimensional exit. Front mouths therefore carry the measured outward bore axis [0,0,1] in runtime coordinates. The solver derives a short axis segment to the native solid support plane plus radius and margin, then solves the exterior path to that generated point and returns to the unchanged actual mouth. No route station is authored. The complete rounded runtime polyline, including the exit segment, is continuously certified against the native solid. Body, mouth coordinates, bore lengths, cord radius, rest lengths and visible connection graph remain unchanged.

Final cord solve preserves the original estimated 2 mm radius and all four measured bore mouths. The generated mouth-axis collar moves only the solver free-route endpoint outside the native support plane and includes the actual mouth in the final certified path. The exact rounded caches pass continuous signed-distance and self/interstrand tube gates.
