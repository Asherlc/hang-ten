# Captain Fingerfood DUAL cord-entry correction

The human app review reported that the cord did not pass through the visible holes. Captain Fingerfood’s [title image](https://cdn.shopify.com/s/files/1/0602/4547/5542/files/DualTitelbild.jpg?v=1739704755), retained as `evidence/captain-fingerfood-dual-title.jpg` (SHA-256 `f57fb751f63c5258e8cb85a9d0f0ad27f6b9cb5eede94b5e1caccc496ec9468e`), shows the orange leads entering the **front recess floor openings**. The independent [DualP1 view](https://captainfingerfood.rocks/cdn/shop/files/DualP1.jpg?v=1739704755), SHA-256 `b67f397ceefa3054f7d6ac038a8459fe8389753713ebb97274acc1a17a6de5c8`, supports the same approach. These exact retained images were approved by the user on 2026-09-29.

The native floor-to-back daylight bores were already correct. Their front mouths are runtime `[±0.026, 0.001, −0.005]` meters; their rear mouths are at Z = −0.015 m. The old shortest routes approached the front mouths from the rear in three of four poses, leaving the front recess visibly empty. Continuous wood clearance passed because the bore is a real void. Clearance alone did not enforce the evidenced entry direction. The renderer used the stored routes faithfully; this was an authoring/solver error.

Each visible lead now specifies the native front-facing `mouthAxis: [0,0,1]`. The existing collar solver derives its exterior endpoint from the native solid support plane and keeps its final point at the actual front floor mouth. No route points or hidden connection are authored. The two leads remain independent; retained evidence still does not establish how they connect behind the board.

The vertical pocket pose also exposed a limitation of independently preferred section planes. One lead first used the other occupied bore; reserving the other generated collar prevented that shortcut, but both preferred routes then reached the same outer-lip area. The strict tube check correctly rejected both candidates. The solver now preserves any already-valid preferred route and searches bounded, deterministic signed section rotations only after a conflict between collared free leads. It resettles hanging height and certifies the exact rounded path for each candidate. The actual native mouths, bore-axis directions, fixed support, cord radius and rest length remain unchanged. A generated collar exterior point can move along that same axis when the existing solver clearance-margin retry increases; each attempt retains and certifies its derived collar. This is a bounded section approximation, not a global shortest-path or full rope-physics claim.

Parallel capsule reservations use the exact cross-section radius `sqrt(R² − d²)` with a conservative circumscribed polygon. Unsupported oblique capsule reservation fails explicitly. Rotated candidates can instead route against the actual native section without that planar helper, and must still pass full 3D solid and whole-path tube certification.

They include the initial failing front-entry regression, the closed two-hole occupied-bore and near-coincident-lip regressions, deterministic apply/check, and continuous clearance plus self/interstrand tests for all four canonical poses. Front/side/top before-and-after technical views use the unchanged USDZ and exact stored route caches. Native source, USDZ, descriptor, poses’ rotations/cameras, fixed anchor and cord dimensions are unchanged.
