# ARView.CameraMode.nonAR

A mode that creates a fully virtual environment with no relationship to the real world.

```
case nonAR
```

## Discussion

Use this mode to create pure virtual 3D environments using [`ARView`](/documentation/RealityKit/ARView).
RealityKit doesn’t place `.nonAR` content into the real world and, as a result,
doesn’t require a front-facing device camera.
