Both independent reviewers agree that no renderer rewrite is currently supported. The earlier full-workflow hand-OFF pass was an overbroad inference from one correct next-active frame. Its rest frame failed, and a new OFF run fails both transitions. All historical reports and exact images remain retained alongside explicit corrections.

The next experiment isolates a single BoardModelSurface before construction of the normal RootView tabs, navigation, workout, or hand hosts. It reuses the existing loader, native model, camera and synchronization path. A fixed viewport and scripted none → active → preview → active → preview sequence remove touch, AX polling, repeated workout ticks and layout changes from the primary measurement. The first correct workout highlight coincided with a 68-point hand-slot insertion and board resize; it therefore does not independently prove prompt material ingestion.

Wait for model loading and viewport settlement. Record requested state and actual scene mutation separately; retain exact screenshot capture start/end times. Sparse application/window activation, host ownership, actual scene identity and CPU state records accompany captures. Disable the existing 1 Hz file sampler in this route. Optional SceneEvents.Update counting stays in memory and is compared separately with the subscription absent; it is not a render/presentation counter or a proposed fix. Primary captures use no touch, resize, camera nudge, visibility toggle or AX polling.

Every transition and final settled frame must be correct; a later successful phase does not erase an earlier failure. A standalone pass implicates surrounding context collectively, not any single removed variable. A failure narrows investigation to the isolated rendering boundary. Physical-device follow-up is conditional on availability and authorization; no hardware claim follows from Simulator evidence.

The committee initially differed on host consolidation versus retaining the current host. Re-scoring the complete OFF sequence resolved that disagreement. On-demand hand images and combined scenes are deferred, not selected fixes.
