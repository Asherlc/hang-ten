**SceneEvents.Update cannot prove that a frame rendered or was presented.** Its diagnostic value is narrower:

- Counter stops alongside inactive/background application state: investigate environment/lifecycle before scene ingestion.
- Counter stops while the application appears active: investigate update delivery or host activation; this still does not prove a paused renderer.
- Counter advances while CPU state is correct and pixels remain stale: simulation/update delivery continues; ingestion, rendering, or presentation remains unresolved.
- Instrumented run passes while the uninstrumented run fails: instrumentation is a confounder, not a repair.

Likewise, enabled or active entities do not certify GPU presentation.
