The coordinator creates the exact existing scene lazily, attaches its root and camera to RealityRenderer, and retains the unchanged mesh/CustomMaterial/light rig/orthographic camera. The unchanged live path keeps its existing gestures. Image gestures have only been syntax checked; interactive fidelity is a later gate, not claimed by the static test.

The completion callback means Apple's corresponding Metal command buffer completed. It exposes no command-buffer status, so this is not an independent GPU-success assertion. Its callback timestamp is recorded before the MainActor hop. Current revisions then use eager CIContext CGImage conversion. A stale completion is discarded after GPU completion without converting or publishing. There is no blocking GPU wait. Conversion and PNG encoding/writing run synchronously on MainActor, an explicit prototype latency limitation. Published images are immutable files, SHA-bound and capped at 64 per coordinator; output edges over 4096 pixels fail closed rather than silently reducing resolution. No periodic observer/render loop/cache is added.

Texture interpretation is an explicit feasibility choice: bgra8Unorm_srgb render target, sRGB Core Image input and RGBA8 sRGB CGImage output, transparent CGColor background, EDR disabled, untouched renderer tone-mapping default recorded. Whether RealityRenderer supports this format and preserves alpha is a runtime gate. CGImage metadata and whole cream/black composition are evidence; no pixel sampling or reference-image manipulation. UIImage uses `.up` and no coordinate transform: whole live/image orientation comparison must verify this convention. No guessed flip is applied.

A new request clears the old displayed image immediately. Only the latest still-active revision can publish. Disappearance invalidates requests but cannot cancel public RealityRenderer work; resources remain until callback and required conversion (or stale discard). Submission errors fail closed and preserve potentially in-flight ownership; no retry or uncertain reuse. Missing callback is bounded by the external static-run deadline and exact app termination, not an invented cancellation API.

First static success requires actual same-content hands visible without clipping, correct pose/orientation/highlight, current PNG publication, zero live hand make counts and zero public ARView at publication census. Offscreen scene constructors are legitimate. Whole screenshot alone does not prove alpha or continuous absence of framework hosts.
