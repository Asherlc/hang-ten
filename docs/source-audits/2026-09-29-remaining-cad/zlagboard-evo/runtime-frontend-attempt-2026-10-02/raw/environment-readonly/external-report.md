# Supporting report, not a diagnosis

A developer reported poor rendering in a second RealityView in Simulator when using tabs or push navigation, while their physical-device build appeared correct. The June 2025 thread has no replies or Apple confirmation in the retrieved page. It supplies an independent first-person anecdote, not proof of the mechanism in Hang Ten or of hardware correctness.

Source: [iOS Simulator can only render 1 RealityView](https://developer.apple.com/forums/thread/786509), read 2026-10-02.
