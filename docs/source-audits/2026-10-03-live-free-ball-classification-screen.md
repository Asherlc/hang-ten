# Accepted free-ball outside classification: closed speed screen

Native-only copied sources. The original 240 Hz rope model, QPs, merit,
convergence experiment, material/diameter, sliding/coupled motion, original mesh
and all swept/physical gates remain. This successor changes the intermediate
floating classification contract; it does not assert universal equality with
the original parity routine's rounded intersection/deduplication behaviour.

A positive typed segment bound supplies a surface-free ball at either endpoint.
The fused query supplies such bounds only after both endpoints are classified
outside, initially by original parity and thereafter by induction. Anchors store
the exact board-frame points queried, with immutable radii, and are installed
only after geometry and CCD acceptance. Every query proves outward-rounded
movement strictly smaller than the stored lower radius; unknown/boundary cases
retain original parity. Arrays have value semantics, are bound to the immutable
collider and rope/point indexing, and are absent after checkpoint restoration.
Adjacent segment bounds may supply the larger radius, never their sum.

The absent primitive failed the classification fixture (RED); its implementation
passed open boundary, nonfinite, outside-source and value-copy fixtures (GREEN).
Independent exact-rational checks passed 10,000 new movement upper bounds, along
with the previous 30,000 support/axis/BVH cases. The optimized scalar LLVM again
contains no unsafe floating arithmetic flags. A scoped Astra mechanism review
found no conceptual blocker and required original-parity validation.

From a cold checkpoint after step120, the verification window121–140 evaluated
the original parity for **all 28,280** claimed skips. There were **zero**
disagreements. A separate untimed candidate used actual skips; both runs retained
identical persisted checkpoints, anchors, correction decisions and skip counts.
Against the independently propagated current control, every pose was identical;
all original-mesh/material checks passed and each side used **75 QPs** with zero
caps/retries. The strict-reference step140 difference is **1.728 µm**. Restoration
cleared anchors; invalid-dt rollback preserved both checkpoint and anchor bits.
The historical 120-step prefix check compares correction count/alpha/movement/
strain, not complete persisted-state identity.

Seven alternating cold 20-step windows, each beginning without anchors, gave
median total ratio **0.839396**, failing the fixed **<=0.80** speed gate. Every
candidate includes first-step certificate acquisition and subsequent construction,
fallbacks, metrics and CCD inside the step clock. Ratios ranged 0.655–0.972. The
accuracy evidence is useful; it does not supply the required performance result.
This version is closed without gate changes, full540 trajectory, simulator,
adoption or normal-speed working-video claim.
