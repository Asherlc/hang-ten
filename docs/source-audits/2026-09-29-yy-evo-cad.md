## Native source and package

`Hangboards/yy-verticalboard-evo/yy-verticalboard-evo.FCStd` is the only geometry
source. It contains a fully constrained Sketcher profile, native PartDesign pad,
outer fillet, scalloped tier pad, five ramp pockets, two jug bearing cuts, independent
blind pockets and inclined subtractive lofts, the through handle, and mouth
chamfers. Contact surfaces are native `PartDesign::SubShapeBinder` references to
the final solid, with explicit ID bindings. No imported or frozen shape features,
Python geometry proxies, texture objects, or material assignments are retained.

The throwaway authoring program is
`.context/supreme-zebra-next-cad-evo/author_evo.py`; it is not a build dependency.
The reviewed manifest was embedded with `Tools/HangboardCAD/set_board_manifest.py`.
The old committed `board.json` and raster are removed; builds generate metadata
from the FCStd and load only the unbound USDZ and hash-bound descriptor.
