# Exterior support direction necessary coverage screen

Owner `strong-owl-live-physics`, same mesh and fixed source/corrected production
states as the directional free-region checkpoint. No app/physics change.

A new zero-only whole-capsule certificate tested 256 fixed Fibonacci sphere
directions plus six coordinate directions. All actual mesh vertices define each
support value, so an exterior separating plane would clear every actual triangle;
this is not a hull collider or an inside/contact replacement. Uncertain links
retain the original query. Directions and the necessary coverage threshold were
fixed before the run.

The ordinary-float discriminator proposes clear **50 of 150** non-tube root
residual links in each state, leaving 100. It fails the predeclared **100-of-150**
coverage gate. No directions were added/fitted, no directed witness acceptance or
native timing followed, and no candidate or physical step was adopted. Sampling
directions is not a proof that no separating plane exists; the measured screen
closes only this fixed direction set. The coverage gate is a heuristic screen,
not a claimed lower bound on query time.

Opus independently classified the links: most wrap the extruded exterior profile,
with a smaller group near the mouths. It recommends an exact different family:
all global support planes parallel to X, evaluated as separation from the entire
YZ projection of actual vertices. Unlike the closed fixed set, that family has no
sampled-direction resolution error. A convex envelope would be used only for
exterior free-space certification; points near/inside it would retain original
triangle queries, including the bores. This successor has not been measured here.
