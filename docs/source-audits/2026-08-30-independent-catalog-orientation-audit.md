# Independent catalog presentation and orientation audit

Reviewed: 2026-08-30

## Method and decision rule

The repository was used only to enumerate review targets after the evidence
review began. For each target I independently searched for the manufacturer and
opened the current first-party product page. Separately addressable first-party
images, manuals, guides, catalogs, or collection pages are listed individually
as Markdown links with an explicit evidence role. A product-page URL never
stands in for an image URL: an em dash means that no separately addressable
media was recorded and the row's limitation controls the claim.

The manufacturer evidence, not an existing asset, JSON value, or earlier audit,
decided whether another face, reverse, end, side, rotation, or mounting
orientation is physically usable. After that decision, the package was checked
only to map its already-declared hold records to the supported presentation. No
image detection, segmentation, registration, tracing, vectorization, generated
mask, automatic cropping, or geometry generation was used.

`All N contacts` below means every package hold record was checked after the
physical presentation decision. A zero-contact view is stated explicitly.
"Current page does not distinguish legacy revision" means the manufacturer is
still first-party authority for the product family, but does not provide enough
current evidence to merge, rename, redraw, or otherwise alter the historical
revision. Those packages remain separate and no unsupported correction is made.
