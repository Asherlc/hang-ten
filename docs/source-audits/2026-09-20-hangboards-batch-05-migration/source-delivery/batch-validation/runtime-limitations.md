# Runtime coverage
The six current GLBs were imported with trimesh and VTK, rendered in VTK, and structurally checked. Exterior-contact ray tests are separate, geometry-based tests, not a browser or phone benchmark.
An additional Chromium/SwiftShader browser probe could not complete in this execution environment: binary-read/payload errors prevented model loading. That probe is NOT reported as passing, and its unfinished viewer is NOT included as a finished deliverable. The user application and a physical target phone remain untested.
