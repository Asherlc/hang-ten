# Immutable face planes and typed clearance bounds: closed speed screen

Native copies only. Product sources and seated cords are unchanged. The exact
face-normal census justified one current-fused-pipeline screen; it was a subset
reassessment of the old four-direction plane family, not a new culling principle.
The new mechanism uses immutable plane storage and explicitly typed conservative
clearance lower bounds instead of the prior mutable hint cache's nil receipts.

The absent bound implementation failed the same-side scalar fixture (RED).
The implemented support bound passed positive/negative separation, crossing,
nonfinite/zero direction and guarded-BVH scalar fixtures (GREEN). This fixture
does not prove every floating operation or optimized instruction sequence.

At fixed original-rate step140, the candidate and current control have exactly
the same pose, two QPs each, and no caps/retries. The converged strict-reference
difference is 1.728 µm. All 279 link bounds satisfy the original clearance oracle
within the registered 1 nm diagnostic allowance; none needed final-query fallback.
The minimum oracle slack is positive, 1.65e-17 m. Independent original-mesh
geometry/material checks pass: strain 0.001517%, material error 0.0933 µm,
clearance margin 99.941 µm. These are checkpoint facts, not generic certification.

Seven alternating complete-step cold pairs gave median candidate/control ratio
**0.886607**, failing the fixed **<=0.80** speed gate. Candidate times were
4.56–4.83 ms. A subsequent instrumentation-only split preserved correction traces,
metrics, pose/reference differences and receipt counts/slack exactly. Its ratio
was **1.019577**, also failed. Paired median batch cost was 2.749→2.639 ms;
final metric cost 0.184→0.181 ms; total 5.253→5.400 ms. The first timing gain is
therefore not a stable speed claim. The support arithmetic consumed most of the
work avoided by culling. The immutable representation solves cache aliasing and
repeated final clearance work, but not this performance gate.

A scoped read-only Astra source audit found no blocking coverage/propagation
branch. It required operation-level directed rounding and optimized-IR inspection
before a certification claim. Those later proof/trajectory stages are not
completed because this version closes at the speed checkpoint. Per-link CCD
consumption on subsequent steps is not established by this one-step screen.
No trajectory, simulator, app adoption, or real-time video follows.
