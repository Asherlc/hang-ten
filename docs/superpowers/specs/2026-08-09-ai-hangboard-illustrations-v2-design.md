# AI Hangboard Illustrations V2 Design

## Goal

Create a separate, more polished AI-rendered illustration set while using the
deterministic previews as strict geometry references.

## Design

For each of the 32 boards, provide two references to the built-in image tool:
the deterministic flat preview for silhouette and hold layout, and the original
catalog render for physical character. Produce a warm editorial illustration
with crisp contours, simple color-blocked planes, restrained depth, and a
uniform parchment background.

Preserve the board's outer silhouette, disconnected pieces, center gaps, and
major hold count and placement. Add no text, logos, bolts, hands, wall scene,
photographic texture, or dramatic shadow. Save results under
`docs/hangboard-generative-catalog/ai-illustrations-v2/` without replacing the
deterministic previews.

## Review

Generate and inspect a representative pilot first, adjust the shared prompt at
most once, then produce all 32 assets and a labeled contact sheet. Record weak
boards honestly and regenerate only material silhouette/layout failures.
